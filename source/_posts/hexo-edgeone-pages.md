想拥有一个自己的博客，写文章、放照片，让别人通过一个网址就能看到？

这次我用自己的开源博客 **my-blog**，把搭建过程整理成一份可以照着操作的小教程。你不必先学会编程，也不用自己管理服务器。

**整个过程只有三件事：复制一份博客 → 让腾讯云把它放到网上 → 配上自己的网址。**

最后一步可以晚点做。先让网站打开，再慢慢改成自己喜欢的样子。

## 开始前，准备什么？

- 一个 [GitHub 账号](https://github.com/)：用来保存你的博客文件。
- 一个腾讯云账号：用来开通 EdgeOne Pages 网站托管服务，按提示完成账号准备。
- 一个域名，例如 `example.com`：相当于网站的门牌号。没有也可以先部署，再用平台提供的访问入口查看。

本文用 Cloudflare 管理域名解析。如果你的域名由其他平台管理，最后添加记录时去对应平台操作即可。

服务和域名是否收费，以开通页面为准；不用因为这篇教程额外购买云服务器。

## 第一步：复制一份现成的博客

打开项目：[my-blog](https://github.com/tdm2psn-star/my-blog)。

1. 登录 GitHub，点击页面右上方的 **Fork**。
2. 选择自己的账号，仓库名称保留 `my-blog` 即可。
3. 点击 **Create fork**，等待复制完成。

你可以把“仓库”理解成存放博客的文件夹。复制后，这份博客就保存在你自己的账号下了。

**怎么确认成功？** 页面上方显示的是 `你的账号 / my-blog`。

这是复制一份带有示例内容的博客。网站上线前，记得把作者介绍、文章、照片、公众号和收款码等示例资料换成自己的，不需要的就移除。

## 第二步：把博客交给腾讯云

进入腾讯云控制台，找到 **EdgeOne → Pages**，选择**导入 Git 仓库**。部分新版页面可能使用 Makers 名称，以实际界面为准。

接下来：

1. 按提示连接 GitHub，授权访问刚才复制的仓库。
2. 选择你账号下的 `my-blog`。
3. 部署分支选择 `main`，可以理解成网站平时使用的正式版本。
4. 框架有 **Hexo** 就选 Hexo；没有就选“其他”，按下表填写。

| 页面上的选项 | 填什么 |
| --- | --- |
| 根目录 | 保持仓库根目录，通常是 `./` |
| 安装命令 | `npm ci` |
| 构建命令 | `npm run build` |
| 输出目录 | `public` |
| Node.js 版本 | `22.21.1` |

这些命令负责把文章文件变成网页，先照填即可。项目里已经保存了这套配置；如果页面自动填好了，核对一致就行。

确认页面上的服务区域、额度和费用提示，再点击部署。第一次需要安装工具、生成网页，等状态变成**部署成功**后再继续。

**怎么确认成功？** 打开控制台提供的网站访问或预览入口，能看到博客首页，点开文章也正常。

## 第三步：给网站添加自己的网址

如果你只想先试用，做到上一步就可以了。

有自己的域名后，进入刚才的腾讯云项目，打开**域名管理 → 添加自定义域名**。

例如，你拥有 `example.com`，想把博客放在：

```text
blog.example.com
```

就在这里填写这个完整网址的域名部分，不要加 `https://`。

按提示完成域名验证，保存页面给出的 **CNAME 目标地址**。它是腾讯云分配给网站的接入地址，下一步要用，**直接复制，不要自己编写**。

如果选择包含中国大陆的服务区域，域名需要满足相应备案要求，按控制台提示办理或选择适合自己的区域。[腾讯云域名接入说明](https://pages.edgeone.ai/document/custom-domain)

## 第四步：到 Cloudflare 给网址“指路”

这一段适用于**域名已经由 Cloudflare 管理**的情况。本文的 `cbsbm.cn` 就是这样配置的。

打开 **Cloudflare → 你的域名 → DNS → Records**，点击 **Add record**。

以 `blog.example.com` 为例：

| 选项 | 填写内容 |
| --- | --- |
| Type（类型） | `CNAME` |
| Name（名称） | `blog` |
| Target（目标） | 刚才从腾讯云复制的 CNAME 目标地址 |
| Proxy status（代理状态） | **DNS only，灰色云朵** |
| TTL | `Auto` |

**名字填 `blog`，不是把整段网址粘进去；目标地址不带 `https://`，也不带后面的页面路径。**

这里选择灰云，让 Cloudflare 只负责告诉浏览器“网站在哪里”，网页由腾讯云提供。橙云还会增加一层 Cloudflare 代理，本教程先不使用。[灰云与橙云的区别](https://developers.cloudflare.com/dns/proxy-status/)

如果腾讯云还给出了域名验证记录，也按提示一并添加。验证用的 CNAME 同样保持灰云。

如果已经有一个同名记录，先看清它是不是旧网站的地址，再决定是否替换。不要删除其他网站或邮箱的记录。

> 我们的测试网址是 `eo-test.cbsbm.cn`，所以在 Cloudflare 里名称填的是 `eo-test`。你部署自己的博客时，要换成自己的名称和腾讯云提供的目标地址。

## 第五步：打开 HTTPS，检查网站

回到腾讯云项目，确认域名已接入，再按页面提示申请或关联 HTTPS 证书。有额外验证要求就照着完成，等证书状态正常。

然后打开：

```text
https://blog.example.com
```

检查四件事：

- 首页能打开。
- 文章能点进去。
- 图片能显示。
- 浏览器没有证书警告。

灰云模式下，网站证书由腾讯云这一侧配置；只修改 Cloudflare 的 SSL 设置，不能代替这一步。

最后，在 GitHub 仓库中打开 `_config.yml`，找到 `url`，改成准备长期使用的网址，例如：

```yaml
url: https://blog.example.com
```

保存修改后会再次部署。我们的项目目前保留的是 `https://cbsbm.cn`；如果你复制了项目，需要换成自己的正式地址。仅临时测试时，不必来回改它。

## 第六步：写下第一篇文章

第一次可以直接在 GitHub 网页上操作，不急着安装本地工具。

1. 打开自己的仓库，进入 `source` → `_posts`。
2. 点击 **Add file → Create new file**。
3. 文件名填写 `我的第一篇文章.md`。
4. 复制下面的内容，把标题、日期和正文换成自己的。

```markdown
---
title: 我的第一篇文章
date: 2026-10-27 12:00:00
categories:
  - 杂文
---

你好，这是我的第一篇博客。

以后想在这里记录生活、学习和有趣的事情。
```

点击 **Commit changes** 保存。如果页面询问保存位置，个人练习时可以直接保存到 `main`；多人维护的仓库按团队流程操作。

腾讯云收到更新后，会重新生成网站。等部署成功，再打开博客，就能看到新文章。

**想改旧文章？** 打开对应文件，点击铅笔按钮修改，再保存即可。技术文章的分类填写 `教程`，杂文填写 `杂文`，摄影填写 `摄影`。

## 遇到问题，先看这里

| 现象 | 先做什么 |
| --- | --- |
| 腾讯云提示构建失败 | 回到第二步，核对五项配置，再看部署日志里的具体报错 |
| 平台提供的入口能打开，自己的域名打不开 | 检查域名是否绑定、DNS 是否填对、证书是否正常 |
| 网站还是旧内容 | 先确认最新部署成功，再刷新或用无痕窗口打开 |
| 文章有了，图片没有 | 确认图片也已上传，文件名大小写和文章里的地址一致 |

**记住：平时更新文章，只需要修改博客文件并保存，不必重新配置域名。**

域名和部署设置完成后，就把注意力放回写作。以后忘了怎么搭建，回来按这六步再走一遍就好。
