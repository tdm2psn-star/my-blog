# Local third-party assets

The files under `source/pluginsSrc/` and `source/vendor/` are local copies of
the static assets used by the AnZhiYu theme. Hexo copies them into `public/`
when the site is built, so visitors do not need to fetch these dependencies
from third-party CDNs.

original upstream provenance; see the Git history and theme configuration for
the replaced URLs.
